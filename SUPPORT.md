# Support

## Where to get help

- **Usage questions, host setup, and workflows:** GitHub Discussions on this repository.
- **Bug reports and reproducible defects:** GitHub Issues using the bug report form.
- **Security problems:** see `SECURITY.md`, never a public issue.
- **Host or catalog problems** (skill discovery in a specific coding agent, `skills.sh` indexing):
  use the support channel of that host or catalog when the problem is on their side.

## Before asking

1. Check the README troubleshooting section.
2. Check [`references/compatibility.md`](skills/agentic-rd-skill/references/compatibility.md) for the
   path and invocation used by your host.
3. Search existing issues and discussions.

## What support covers

This is a free, maintainer-run project. Support covers defects caused by the skill package, the
workflow CLI, or documented behavior. It does not cover third-party coding agents, customized
deployments, or consulting work.

## Response expectations

Best effort, usually within a week. Issues without version information or a reproduction may be
closed with a request for details.
